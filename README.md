## 🧠 Core Clinical & Theoretical Foundations

### 1. schizoOS Cognitive Architecture *(Invented by Dr. Bheemaiah Anil K)*
Traditional psychiatry frequently treats schizophrenia, psychosis, and severe anxiety as uninterpretable neurological "noise." The **schizoOS** paradigm models the human mind as a cybernetic multi-plane cognitive system:
* **The Autopilot (Subconscious Loop)**: Fast, habituated reflex scripts, trauma triggers, and Default Mode Network (DMN) rumination. When over-aroused, the autopilot generates auditory and perceptual distortions as involuntary prediction errors.
* **Manas (मनस् - Sensory Gate)**: The rapid perceptual filter receiving raw sensory inputs (sights, sounds, visceral somatic pulses).
* **Chitta (चित्त - Memory Lake)**: The reservoir of stored impressions (*samskaras* / *vasanas*) that continuously feeds predictive imagery to the autopilot.
* **Buddhi (बुद्धि - Mindful Witness & Discernment)**: Higher metacognitive discernment, conscious reality testing, cognitive reframing, and intentional choice.
* **Bodhichitta (बोधिश्चित्त - Awakened Compassion)**: The transcendent heart space of unconditional warmth, universal loving-kindness, and gentle self-forgiveness that disarms panic alarms.

Through schizoOS, users learn to observe thoughts arising in the *Chitta-Autopilot* circuit and install *Buddhi* circuit breakers without fighting or fearing their inner experiences.

## 🚀 Getting Started

### Prerequisites
* **Node.js**: v18.0.0 or later (Node.js 20+ recommended)
* **npm** or **bun**: Package manager installed
* **Google Gemini API Key**: Obtainable from [Google AI Studio](https://aistudio.google.com/) *(optional: the system contains built-in clinical fallback responses if no key is provided)*

### Installation

1. **Clone or export the repository**:
   ```bash
   git clone https://github.com/vayu-vaidya/wallmiki-e-psychiatrist.git
   cd wallmiki-e-psychiatrist
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
   Edit `.env` and configure your API key:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```

4. **Start the Development Server**:
   ```bash
   npm run dev
   ```
   The application will start on **`http://localhost:3000`**.

5. **Build for Production**:
   ```bash
   npm run build
   ```
   This compiles the Vite frontend into `dist/` and bundles the Express server into a standalone `dist/server.cjs` file using `esbuild`.

6. **Run Production Server**:
   ```bash
   npm start
   ```
